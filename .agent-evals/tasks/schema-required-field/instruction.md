ExploreBench task YAMLs get edited over time (a reference moves, a line range is fixed), and nothing in an explore_runs artifact says which version of a task a run scored, so we end up comparing runs that were scored against different ground truth. Make `explore run` record a `digest` on every entry of the artifact's `tasks` list: a stable hash of the task's query and references, which changes when either of them changes. The explore_runs format should require it, so that an artifact whose task entries lack a digest fails validation. Commit your change.
